# Kaggle civil-engineering dataset catalogue

`kaggle_civil_datasets.csv` lists 63 Kaggle datasets relevant to the book, mapped to chapters.
The licence is the one shown on each Kaggle page when checked (November 2026). Licences change, so check the page again before you publish anything.

`book_use` values:
- printable / usable / usable with credit: CC0, CC BY, MIT, Apache, PDDL, US Gov. You may use these with attribution.
- usable share-alike: CC BY-SA or ODbL. Derived data must keep the same licence.
- cite original: a re-upload of UCI, Mendeley or another source. Cite and download the original instead.
- cite only (non-commercial), check licence, training only, check origin: do not reproduce in a commercial book.

Never print images showing identifiable workers, whatever the licence.
No datasets are redistributed in this repository, only references.
