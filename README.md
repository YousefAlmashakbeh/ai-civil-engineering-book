# الذكاء الاصطناعي في الهندسة المدنية: من المبادئ إلى التطبيق
## AI in Civil Engineering: From Principles to Practice — companion code

Companion code for the Arabic textbook by Eng. Yousef Al-Mashaqbeh (The Hashemite University, Jordan).
Every number printed in the book is produced by running these scripts.

| Folder | Content |
| --- | --- |
| `code/` | One script per chapter (`ch2.py` … `ch18.py`), data generators (`ch5_data.py`, `crackgen.py`, `clauses.py`, `ch17_corpus.py`), appendix solutions (`solutions.py`) |
| `notebooks/` | One Colab notebook per chapter, self-contained (helper modules written by `%%writefile`) |
| `figures/` | Figures generated by the scripts (PNG files) |

### Open in Colab
Every notebook opens directly in Google Colab, for example
`https://colab.research.google.com/github/YousefAlmashakbeh/ai-civil-engineering-book/blob/main/notebooks/ch14.ipynb`
(change the chapter number at the end).

### Run
```bash
pip install -r requirements.txt
cd code
mkdir -p fig
python ch14.py      # prints results, saves figures in fig/
```

### Data
Cases labelled «حالة أصلية» in the book are synthetic, generated from physical/code equations with noise by these scripts.
They are for teaching, not design. Real open datasets (UCI, METU, SDNET2018, RDD2022, KW51, …) are loaded in Colab;
check each dataset's own licence page before reuse.

### HU-CP crack dataset (Chapter 12)
`code/ch12_hucp.py` uses the walls subset of HU-CP v1.0 by default (set `HUCP_SURFACE=P` for pavements) (CC BY 4.0): https://doi.org/10.5281/zenodo.23836570

### Author's experimental data
Chapters 8 and 13 use published literature (Almusallam et al. 1996; Bhargava et al. 2008; Mousavi et al. 2023; SHRP 2 R06A) together with generated teaching data (`ch8_lit.py`, `ch13_lit.py`).
